# বাজার দর (BazarDor)

## Short Description
**BazarDor** is a modern, real-time commodity and market price tracking web application. It helps users view daily market prices, category-based navigation, and price fluctuation trends (increases or decreases) for essential daily commodities such as rice, lentils, oil, and spices.

## Technologies Used
* **Framework:** Next.js (App Router)
* **Styling:** Tailwind CSS, DaisyUI
* **Authentication:** Better Auth (Google & GitHub Social Providers)
* **Language:** TypeScript
* **UI Feedback:** React Hot Toast

##  Key Features
1. **Real-Time Price & Category Navigation:** Displays live market rates, categorized product navigation, and dynamic percentage indicators for price changes.
2. **Secure Authentication System:** Fully integrated auth flow supporting email/password registration alongside Google and GitHub social logins.
3. **Protected Routes & Access Control:** Secures application routes and category links, automatically redirecting unauthenticated users to the sign-in page with helpful feedback.
4. **User Profile Management:** Allows users to view their account details, active status, and navigate to dedicated update views.
5. **Interactive UI & Localized Notifications:** Fully responsive design paired with real-time, localized Bengali toast notifications (`react-hot-toast`) for smooth user interactions.
